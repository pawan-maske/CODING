Questions for Interview Preparation:
Here’s the cleaned, de-duplicated, and categorized list of interview questions:

---

### **Java Core**  
1. Java 8 features.  
2. Difference between abstraction and encapsulation.  
3. What is overriding? Explain with class/interface example.  
4. Difference between `Comparable` and `Comparator`.  
5. What is a tag interface? When is it used?  
6. Explain `equals()` method and in which class it is present.  
7. What is immutable in Java? Give syntax for creating an immutable class.  
8. Use of `Object` class in Java.  
9. Difference between `forEach` in Collection vs. Stream.  
10. How to remove duplicates from a list/set.  
11. Difference between `ArrayList` and `LinkedList`.  
12. Memory allocation in Java.  

### **Collections**  
1. Internal working of `HashMap`.  
2. Changes in `HashMap` working in Java 8.  
3. Difference between `Map` and `FlatMap` (Streams).  
4. Intermediate operations in Streams: `filter`, `map`, `sorted`, `distinct`.  
5. `ConcurrentHashMap` working.  

### **Multithreading**  
1. How to make a thread sleep for 2 minutes?  
2. Executor Service.  
3. Difference between asynchronous and synchronous.  
4. Singleton class in Java.  

### **Spring & Spring Boot**  
1. Difference between Spring and Spring Boot.  
2. Explain `@SpringBootApplication` annotation.  
3. Spring Boot architecture/flow.  
4. Types of dependency injection (DI) in Spring.  
5. What is `@Autowired`? Constructor vs. setter injection.  
6. Spring scopes. When to use `prototype` scope?  
7. Annotations in Spring (`@Service`, `@Component`, `@Repository`, etc.).  
8. Purpose of `DispatcherServlet`.  
9. How does Spring detect dependencies?  
10. Spring modules you’ve worked with.  
11. Spring AOP and Spring Security.  

### **Database & JPA/Hibernate**  
1. Difference between stored procedures and functions.  
2. Joins in SQL (inner, left, right) with examples.  
3. How to connect Spring Boot to a database.  
4. JPA Repository vs. Hibernate.  
5. `@ManyToOne` annotation usage.  
6. How to fetch an entity without its nested object (e.g., `Employee` without `Address`).  
7. Exceptions faced in Hibernate.  

### **REST APIs & Microservices**  
1. What is a microservice?  
2. API Gateway (e.g., Zuul, `@EnableZuulProxy`).  
3. How to secure REST endpoints.  
4. HTTP methods: GET vs. POST, POST vs. PUT, PUT vs. PATCH.  
5. Can POST have an empty body?  
6. HTTP status codes you’ve worked with.  
7. How to develop a REST API.  
8. API authentication methods (JWT, OAuth).  

### **JWT & Security**  
1. JWT token working and its purpose.  
2. How to secure REST URLs.  

### **Exception Handling**  
1. Exception handling in Spring Boot.  
2. Why use custom exceptions? Examples.  
3. Significance of `finally` block.  
4. Can `try` be used without `catch`?  
5. How to create a custom exception.  

### **DevOps & Testing**  
1. Deployment process.  
2. DevOps tools used (Docker, Kubernetes, GitHub).  
3. How to prevent unreviewed code merges in GitHub.  
4. JUnit/Mockito:  
   - How to write test cases for CRUD operations.  
   - How to mock a service.  
   - Testing private/final methods.  
5. SDLC lifecycle.  

### **Coding Problems**  
1. Reverse a number/string (with/without Java 8).  
2. Find longest valid parentheses substring (stack approach).  
3. Find top 3 salaries from `Employee` table using Java 8.  
4. Frequency of characters in a string.  
5. Check if a string is a palindrome.  
6. Print numbers not divisible by 3 but multiples of 9.  
7. Remove duplicates from a string/list.
